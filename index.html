Выбор DNS сервера:
Выберите DNS-сервер для запросов. Cloudflare — быстрый и приватный, Google — надёжный
Тип записи:
A — IPv4-адрес, AAAA — IPv6, MX — почтовые серверы, NS — DNS-серверы домена, CNAME — алиас, SOA — зона, TXT — текстовые записи
Таймаут:
Максимальное время ожидания ответа от DNS-сервера
Задержка:
Пауза между запросами, чтобы не перегружать DNS-сервер
Формат вывода:
Only IP — только адреса, Hosts — для hosts-файла, Classic — подробный вывод
