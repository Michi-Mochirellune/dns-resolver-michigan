# Dns Resolver Michigan

Мини-утилита для массового определения IP-адресов и DNS-записей доменов. Работает прямо в браузере, ничего устанавливать не нужно.

https://michi-mochirellune.github.io/dns-resolver-michigan/

## Возможности

### DNS-серверы
- **Cloudflare** (по умолчанию) — быстрый и приватный
- **Google** — надёжный, всем известный

### Типы записей
- **A** — IPv4-адрес
- **AAAA** — IPv6-адрес
- **MX** — почтовые серверы
- **NS** — DNS-серверы домена
- **TXT** — текстовые записи

### Форматы вывода
- **Only IP** (по умолчанию) — только IP, каждый с новой строки
- **Hosts** — формат для hosts-файла (`IP домен`)
- **Classic** — подробный вывод с пометками `[+]` и `[-]`

### Удобства
- Копирование результатов в один клик
- Экспорт в .txt файл
- Умная очистка дублей — приводит все домены к нижнему регистру (большие буквы заменяет на маленькие) и удаляет повторяющиеся. Например, InstAGraM.cOm и instagram.com станут одним instagram.com.
- Кнопка «Тест сайтов» для быстрой проверки
- Счётчик найденных/ненайденных и ошибочных доменов

### Настройки
- Таймаут запроса (5/10/15 секунд)
- Задержка между запросами (без задержки / 0.5 сек / 1 сек)

### Оформление
- Тёмная и светлая темы с переключением
- Кастомные фоны для каждой темы
- Адаптивный дизайн для телефонов

### Пасхалка
- Нажми 3 раза на заголовок — увидишь приятный сюрприз ❤️

### Языки
- Русский
- English (переключается по флагу)

## Как использовать

1. Вставь список доменов в поле ввода (каждый с новой строки)
2. Нажми «Узнать IP адреса»
3. Результат можно скопировать или скачать
