Мини-утилита для массового определения IP-адресов и DNS-записей доменов. Работает прямо в браузере, ничего устанавливать не нужно.

(Код написан не мною, а при помощи Deepseek, я же просто проверяю и прошу где-то добавить/исправить, мелкие детали я могу и сам в коде поправить)

## Возможности

### DNS-серверы
- **Cloudflare** — быстрый и приватный
- **Google** — надёжный
- **DNS.SB** — какой-то тоже днс
- Выбор нескольких днс для сравнения

### Типы записей
- **A** — IPv4-адрес
- **AAAA** — IPv6-адрес
- **MX** — почтовые серверы
- **NS** — DNS-серверы домена
- **SOA** — информация о зоне
- **TXT** — текстовые записи

### Форматы вывода
- **Only IP** — только адреса (по умолчанию)
- **Hosts** — формат для hosts-файла (`IP домен`)

### Настройки
- Таймаут запроса (5/10/15 секунд)
- Задержка между запросами
- TTL и DNSSEC (вкл/выкл)
- Показывать названия DNS (напр CF: 1.1.1.1)
- Три темы: системная, светлая, тёмная

### Удобства
- Копирование доменов и результатов в один клик
- Раздельная очистка поля ввода и результатов
- Умная очистка дублей (без учёта регистра)
- Импорт списка доменов из файла
- Drag & Drop файла
- Кнопка «Тест сайтов» для быстрой проверки
- Раскрытие полей на весь экран
- Экспорт в TXT, CSV, JSON

### Дополнительно
- Русский и английский языки
- Сохранение темы и языка
- Пасхалка в логотипе
- Toast-уведомления

## Технологии
- DNS-over-HTTPS (Cloudflare, Google)
- Без серверов и регистраций
- localStorage для темы и языка
