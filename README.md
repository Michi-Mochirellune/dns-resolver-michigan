DNS Resolver Michigan — лёгкий веб-инструмент для массового определения IP-адресов по списку доменов.

Основные фичи:

· Резолвинг через Cloudflare DNS или Google DNS — переключайся в настройках в один клик
· 3 формата вывода:
  · Classic — [ + ] domain.com -> 1.2.3.4
  · Hosts — 1.2.3.4 domain.com (можно сразу вставить в hosts-файл)
  · Only IP — только IP, каждый с новой строки (удобно копировать списком)
· Копирование в один клик — кнопка «Копировать» сразу забирает всё из результатов
· Два языка: русский и английский (переключается по флагу)
· Три размера шрифта: обычный, средний, крупный
· Тёмно-фиолетовый неоновый стиль — потому что красота важна
· Полностью работает в браузере, ничего устанавливать не надо
