**Твой карманный DNS-резолвер. Кидаешь список доменов — получаешь IP. Без смс и регистраций.**

Задолбался вбивать домены по одному? Этот резолвер жрёт список из 100+ доменов и выплёвывает готовые IP в любом формате. Хочешь Hosts-файл? Получи. Хочешь под AdGuard? Без проблем.

---

## 🎯 Что он делает

Берёт твой список доменов и прогоняет через DNS-over-HTTPS. На выходе — IP-адреса в том виде, в каком тебе удобно.

### Основной функционал

- **Массовая проверка** — вставил список, нажал кнопку, пошёл пить чай
- **10 типов записей** — от банальных A/AAAA до редких SRV и PTR Range
- **Три DoH-провайдера из коробки** — Cloudflare, Google, DNS.SB
- **Свои серверы** — если не доверяешь корпорациям, добавь свой DoH
- **Умный PTR** — кидаешь IP, он сам разворачивает в обратную зону
- **PTR Range** — диапазон IP? Развернёт каждый адрес и проверит

### Форматы на любой вкус

| Формат | Для чего |
|--------|----------|
| **Only IP** | Просто список адресов |
| **Hosts** | Готовый hosts-файл, кидай в `/etc/hosts` |
| **AdGuard** | Синтаксис `\|\|domain^` для блокировки рекламы |
| **Pi-hole** | Формат `0.0.0.0 domain` для Pi-hole |

### Статистика

После проверки показывает всё, что можно посчитать:
- Сколько нашлось, сколько отвалилось
- Уникальные и дубли
- Мин/сред/макс скорость ответа
- Общее время и размер ответа
- TTL записей
